# Homepage opening posters

Actual captures of the shared LIEUVA GalleryScene using STORY_DRAFT and
storyPresentation(0), prepared with full GPU readiness before capture. Desktop
1440×1000 and compact 390×844 framings use the exact opening camera in the current
story model. Optimized using cwebp quality 86; no enlargement or generated UI.

These are quiet preparation images, selected responsively. They dissolve into
the real cinematic scene after readiness. They do not replace interactive room
assets, are not 4K beauty renders, and do not add a second loading indicator.
Provenance is the existing project-authored geometry/materials. See manifest.json
for dimensions, sizes and hashes, and ASSET_LICENSES.md for project provenance.
