# LIEUVA Agentenzentrale · UI-Konzeptpaket

30 Bildentwürfe in drei Richtungen: CLEAR, ORBIT und ATELIER.

- `index.html`: lokale Bildgalerie mit Konzept- und Seitenfilter.
- `../pdf/lieuva-agentenzentrale-drei-ui-konzepte-2026-09-26.pdf`: vollständiges Konzept mit Vergleich und Änderungsübersicht.
- `01-clear/`, `02-orbit/`, `03-atelier/`: Originalbilder und genaue Generierungsprompts.
- `design-prompts.json`: gemeinsamer Bildbrief und alle Screenvorgaben.
- `konzept-inhalt.md`: wesentliche Erläuterungen in editierbarer Textform.

Die Bilder wurden mit dem integrierten Bildgenerator erstellt, dessen Werkzeug keine separate Astra-Auswahl anbietet. Kein Umbau, Start von Agents oder Deployment der bestehenden Anwendung. Generierte Screens enthalten Beispieldaten. Für Verhalten und Statusfolgen gilt die textliche Spezifikation im PDF.
